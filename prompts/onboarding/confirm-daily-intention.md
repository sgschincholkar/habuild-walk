# Confirm Daily Intention

## Purpose
Review and confirm today's plan.

## Design System
- shadcn/ui
- Tailwind CSS
- Mobile-first
- Light mode only
- Primary: #2D6A4F
- Secondary: #F4F1EE
- Accent: #F9A825
- Font: Inter

## Key UX Rules
- Calm wellness tone
- Large touch targets
- Spacious spacing
- Rounded cards
- Soft warm shadows
- No athletic dashboard styling
- Avoid dense analytics

## Core Elements
- Header section
- Main content cards
- Primary CTA
- Secondary action
- Bottom navigation where relevant

## Behavior
- Keep interactions emotionally supportive
- Use subtle motion only
- Preserve habit-coach tone
