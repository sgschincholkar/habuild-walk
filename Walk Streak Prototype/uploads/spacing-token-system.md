## Base Grid
- 4px base spacing unit

## Horizontal Gutters
- Minimum: 20px
- Preferred: 24px

## Vertical Rhythm
- Small spacing: 8px
- Medium spacing: 16px
- Large spacing: 24px
- Section spacing: 32px
- Major screen spacing: 48px

## Border Radius
- Small: 12px
- Medium: 18px
- Large: 28px
- Pill: fully rounded

## Buttons
- Minimum height: 48px
- Large CTA preferred: 56px
- Horizontal padding: 20–24px

## Cards
- Internal padding: 20px
- Card gap: 16px
- Soft shadow only

## Bottom Navigation
- Height: 72px
- Safe-area aware
- Rounded top container

## Inputs
- Height minimum: 48px
- Large readable spacing
- Comfortable keyboard clearance

## Chips
- Large pill chips
- Comfortable thumb spacing
- Avoid compact layouts

## Shadows
- Warm soft shadows only
- Low contrast elevation
- No harsh dark shadows

## Motion
- Standard transition: 200ms ease-out
- Screen transitions: fade + slide

## Layout Density
- Prefer breathing room over information density
- Never crowd cards tightly
- Keep layouts visually calm
